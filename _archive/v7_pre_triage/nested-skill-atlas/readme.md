## 🎯 Command Surface (v8.3)

### CLI Commands
```bash
# Project Management
atlas init <name>                  # Initialize new Atlas project
atlas status [project]             # Show project status, scores, and active lane
atlas diagnose [project]           # Run pulse | decide diagnostic pipeline

# Adapter & Fleet Management
atlas adapter sync                 # Omni-Sync all projects in your DEV directory
atlas fusion route <task>          # Route a task to the best available sub-agent
atlas fusion agents                # List available sovereign agents

# Scoring & Intelligence
atlas score calculate [project]    # Recompute deterministic business scores
atlas score predict [project]      # Generate 7-day predictive trend analysis

# Portfolio & Governance
atlas portfolio list               # List all projects and their current lanes
atlas portfolio focus <project>    # Set project to Primary Lane (parks others)
atlas portfolio rebalance          # Audit lanes and trigger Capital Governor

# Monitoring
atlas dashboard                    # Open the local web-based business cockpit
```
