# Mapping the Agentic Ecosystem: Platforms with Sub-Agent Delegation

This map identifies AI platforms, CLIs, IDEs, and web environments capable of **delegation**—the ability for a primary AI to spawn, task, and receive results from secondary, specialized sub-agents.

---

### **1. Anthropic Ecosystem**
*   **Claude Code (CLI)**
    *   *Mechanism:* Spawns background sub-agents for heavy tasks like indexing or multi-file refactoring.
    *   *Access:* `npm install -g @anthropic-ai/claude-code` (Early Access).
*   **Claude Desktop (App)**
    *   *Mechanism:* Utilizes "Computer Use" and "Analysis" agents for task-specific handoffs.
    *   *Access:* [claude.ai/download](https://claude.ai/download)
*   **Claude.ai (Web) - "Claude Coworker"**
    *   *Mechanism:* Designed for organizational delegation between "Manager" and "Worker" roles.
    *   *URL:* [claude.ai](https://claude.ai) (Enterprise/Team plans).

### **2. Google Ecosystem**
*   **Gemini CLI**
    *   *Mechanism:* Uses `invoke_agent` to spawn specialized agents (e.g., `codebase_investigator`) in isolated contexts.
*   **Gemini 2.0 (Web)**
    *   *Mechanism:* Support for "Tools" that function as sub-agent handoffs for code, search, and planning.
    *   *URL:* [gemini.google.com](https://gemini.google.com)
*   **Project IDX / Android Studio**
    *   *Mechanism:* Orchestrates "Gemini Code Assist" background agents for debugging and generation.
    *   *URL:* [idx.google.com](https://idx.google.com)

### **3. OpenAI Ecosystem**
*   **ChatGPT "Operator" (Web/Desktop)**
    *   *Mechanism:* Primary agent delegates browser actions and file manipulation to specialized sub-routines.
    *   *URL:* [chatgpt.com](https://chatgpt.com)
*   **OpenAI Swarm (Framework)**
    *   *Mechanism:* A specific SDK for multi-agent "Handoffs."
